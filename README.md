# Каспий: ретро-прогноз уровня и раннее предупреждение для объектов ЛУКОЙЛа

Пайплайн отвечает на вопрос: **можно ли было заранее увидеть, что уровень Каспия опустится ниже отметки, критичной для объекта, и успеть подготовиться.**
Каждый месяц с января 1998 года модель выпускает прогноз так, как если бы это был «сегодняшний» месяц: она видит только данные до этой даты. Затем прогноз сверяется с тем, что произошло.

## Запуск

```bash
pip install pandas numpy statsmodels
python run.py            # полный прогон, ~7 мин (SARIMA переобучается каждый месяц)
python run.py --reuse    # пересчёт тревог и интервалов по сохранённым прогнозам, ~10 с
python report/build.py   # страница report/caspian_report.html с встроенными данными
```

Результаты — в `outputs/`.

## Этапы

| Шаг | Модуль | Что делает |
| --- | --- | --- |
| 1. Данные | `pipeline/ingest.py` | Месячный ряд спутниковой альтиметрии NASA G-REALM (1992–2026), привязка к Балтийской системе высот одной внешней отметкой |
| 2. Прогноз | `pipeline/models.py` | Сезонная «наивка» (база), локальный тренд + сезонность, SARIMA(1,1,0)(0,1,1)12, ансамбль |
| 3. Ретро-прогноз | `pipeline/backtest.py` | 345 точек выпуска × горизонт 1–24 мес.; интервалы и вероятности только по уже проверенным ошибкам |
| 4. Калибровка | `pipeline/backtest.py` | Адаптивный масштаб интервала (adaptive conformal inference): промахи расширяют интервал, попадания сужают |
| 5. Тревоги | `pipeline/alerts.py` | P(уровень ниже порога в ближайшие 24 мес.) ≥ 0,5 → тревога; заблаговременность и ложные тревоги |
| 6. Пороги | `pipeline/config.py` | Отметки объектов с указанием, откуда они взяты |

## Данные и привязка

- Ряд: [NASA/USDA G-REALM, Caspian Sea, target 000270](https://earth.gsfc.nasa.gov/gwm/lake/270) — TOPEX/Poseidon, Jason-1/2/3, Sentinel-6A. Дубликаты дат при перекрытии миссий усреднены, затем — среднее за месяц.
- Привязка к м БС: −29,21 м в апреле 2025 (Минводресурсов Казахстана). Независимая проверка: 1995 год по пайплайну −26,70 м, в литературе около −26,66 м (расхождение 4 см).

## Главные результаты (прогон 27.10.2026)

- Точность ансамбля: средняя ошибка 4 см на 1 месяц, 10 см на 12 месяцев, 16 см на 24 месяца.
- 80%-й интервал накрыл 79,7% фактических значений (без адаптации было 68,5%).
- **Волго-Каспийский канал, порог −28,0 м БС:** уровень впервые ушёл ниже в декабре 2014; инцидент с загрузкой судов на 50% — апрель 2015. Непрерывная тревога — с октября 2013, то есть за 14 месяцев до пересечения и за 18 до инцидента.
- **Исторический минимум −29,01 м БС (Каламкас/Хазар):** пересечение в январе 2023; тревога с января 2022, без ложных тревог.
- **Сетка порогов от −27,6 до −29,2 м:** непрерывная тревога за 7–48 месяцев (медиана 15). Прогноз «как год назад» не даёт тревоги ни разу до пересечения.
- **Текущий прогноз (от октября 2026):** октябрь 2027 — −29,46 м БС (80%: −29,65…−29,32); минимум в ближайшие 24 месяца — около −29,56 м.

## Ограничения

- Порог −28,0 м подобран под инцидент 2015 года. Для реального использования его надо заменить отметкой дна канала по промерам Росморпорта.
- Затор 2026 года вызван заилением после половодья, а не только уровнем моря. Альтиметрия видит половодье лишь косвенно. Индикатор `siltation_flag_experimental.csv` придуман после события и не проверен.
- Ложные тревоги сосредоточены в 2016–2019 годах, когда падение уровня временно остановилось (порог −28,2…−28,5 м: 13–25 месяцев тревоги без пересечения в 24-месячном окне).
- В модель не входят сток Волги, испарение и климатические сценарии. Следующий шаг — добавить сток Волги (ECOMAG или данные Росгидромета) как внешний предиктор.
